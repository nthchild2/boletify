Social glyphs — Instagram, X/Twitter, TikTok — the one place filled icons are used, copied from the real footer in `brutal-glass.tsx`. Each is a 24×24 single-ink SVG drawn with `fill="currentColor"`: inline it so it takes the host text color (and the brand accent on hover, as in the `marketing-web` footer). Shown through `<img>` it can't inherit a color and renders black — on dark grounds, inline it and set `color: var(--color-fg)`.
