**Badge** — small overline pill for sale state, category, or metadata. Reach for it whenever you need a status marker on a card or row.

```jsx
<Badge variant="signal">En venta</Badge>
<Badge variant="rosa">Últimos</Badge>
<Badge variant="oxblood">Agotado</Badge>
<Badge variant="sun">OXXO pendiente</Badge>
<Badge variant="ink">Indie</Badge>
```

Variant carries meaning: `signal`=on sale/primary, `rosa`=urgency/feature, `oxblood`=sold-out/stopped, `leaf`=success/valid, `sun`=warning/pending, `cenote`=info, `ink`=neutral category (glass, adapts to theme). Brand-color variants stay their hue in both themes.
